# 公共场所外语译写规范发布与采用追踪

新规范生效时，管理者需要知道机场、医院、景区、道路标牌和政务网页各自仍引用哪些旧词条，
而不是等市民报错。本服务把语种、场所类别、标准词条、例外说明、依据文件、生效与废止时间
组织成带签名的发布包；责任单位按管理范围订阅后上报不含公众身份信息的标识目录及所用版本；
新旧发布包自动生成可复核的差异与影响清单，系统只提出整改候选，专业人员确认后才要求某个
载体更新。单位可就施工周期或历史建筑申请限时豁免，批准、到期、撤销均以只追加事件记录，
不覆盖原决定；离线回执与重复同步不会让采用进度倒退。旧版发布包继续支持历史查询，但不能
被新建标识下载使用；分批换版期间，公开查询并排展示当前推荐与现场实际的差异。管理者可按
一条规范修订看到受影响载体、责任单位、承诺期限与真实完成比例，并能从任一标识版本反查它
当时合法引用的发布包。

服务通过 HTTP 接口交换业务事件，并使用 SQLite 文件保存本地状态。监听端口由 `PORT` 指定，
数据文件位置由 `DATABASE_PATH` 指定，发布包签名密钥由 `RELEASE_SIGNING_SECRET` 指定
（缺省为仅供开发的内置值）。领域约定见 `docs/domain.md`，接口清单见 `docs/api.md`，
`contracts/entities.json` 记录稳定字段，`fixtures/example.json` 提供不含真实身份信息的示例。

## 本地开发

运行 `make migrate` 初始化数据文件，`make test` 执行现有自动化检查，`make run` 启动服务。
也可以使用 `docker compose up --build` 构建并运行容器，宿主机端口通过 `APP_PORT` 调整。
